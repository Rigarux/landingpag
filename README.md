# Landing Page DCH Multiservicios

Proyecto de la nueva Landing Page para DCH Multiservicios, desarrollada con React, Vite y Framer Motion.

## Filosofía de Diseño 🎨

Para este proyecto y futuros desarrollos dentro de la interfaz, nos regimos por los siguientes principios clave para asegurar una experiencia de usuario del más alto nivel:

- **Impecable Design:** Atención absoluta y milimétrica al detalle. Tipografía refinada, proporciones consistentes, uso intencional del espacio negativo y una estética "dark mode" limpia y premium.
- **Emil Kowalski:** Animaciones fluidas basadas en físicas reales (springs). Las interacciones, los hovers y las transiciones deben sentirse naturales, táctiles y reactivas, sin ser lentas ni intrusivas.
- **Taste-Skill:** La interfaz no solo debe funcionar bien, debe transmitir "buen gusto" (taste). Buscamos una sensación de lujo corporativo, jerarquía visual clara y micro-interacciones que denoten profesionalismo y cuidado.

## Tecnologías Utilizadas
- React 19
- Vite
- Framer Motion (Animaciones)
- Lucide React (Iconografía)
